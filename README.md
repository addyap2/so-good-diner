# So Good Diner

Site vitrine du **So Good Diner** — burgers, kumpir, box à partager et snacking maison à Fréjus.

📍 65 Rue du Général de Gaulle, 83600 Fréjus · [@sogooddiner83](https://www.instagram.com/sogooddiner83)

## Aperçu

Site statique d'une seule page (HTML / CSS / JS, sans dépendance de build) :

- **Hero** vidéo avec logo et accroche
- **Notre maison** — pain artisanal, viande du boucher, sauces maison
- **La Carte** complète avec filtres par catégorie (Sandwichs, Burgers & Wraps, Kumpir, Boxs, Snacking, Menus, Desserts)
- **Avis** clients
- **Galerie** vidéo
- **Contact** avec carte Google Maps

## Structure

```
index.html        Page principale
styles.css        Styles (thème sombre, doré/orange)
script.js         Navigation mobile, filtres carte, animations
assets/img/       Visuels (hero + carte imprimée)
assets/video/     Clips vidéo
```

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrez http://localhost:8000

## À compléter

Des emplacements marqués `[... à compléter]` attendent votre texte :
accroche du hero, présentation « Notre maison », numéro de téléphone et horaires.
